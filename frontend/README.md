# Markopolo 🌌
### Authentic Insights & Professional Discovery Circle

Markopolo is a high-fidelity, community-driven discovery platform designed to surface hidden gems and authentic industry insights through a premium, 3D-accelerated user experience.

---

## ✨ Key Highlights

### 🚀 3D Discovery Engine
- **Infinite Community Pulse**: Smooth, mathematically-seamless 3D "Cover Flow" carousels for verified testimonials.
- **GPU-Accelerated Motion**: Optimized CSS transforms for jitter-free scrolling on high-refresh-rate displays.
- **Visual Continuity**: Dynamic motion aligned with the brand's sapphire and orange aesthetic.

### 🛣️ Interactive Journey Timeline
- **Guided Exploration**: A custom-designed "How It Works" section with an integrated visual continuity line.
- **Precision Alignment**: Precise vertical anchoring connecting the user journey from start to finish.

### 🤖 Marko AI-Assistant
- **Premium Chat Interface**: A vibrant, gradient-themed floating action suite featuring the "Marko" AI guide.
- **Integrated Navigation**: Vertically-aligned suite combining instant AI support with a specialized scroll-to-top engine.
- **Interactive Polish**: Pulse-animated status indicators and glassmorphic header components.

### 🛡️ Production Security Posture
- **Hardened CSP**: Production-ready Content Security Policy (CSP) mitigating XSS and injection risks.
- **Zero-Vulnerability Audit**: Verified 0 high-severity vulnerabilities via comprehensive project-wide audits.
- **Secure Data Handling**: Audited local storage and state management for privacy-first user experiences.

## 🛠️ Tech Stack

- **Core:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom Design System)
- **State Management:** [Redux Toolkit](https://redux-toolkit.js.org/)
- **Animations:** AOS (Animate On Scroll) + Custom 3D Keyframes
- **Icons:** [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### 1. Prerequisites
- **Node.js**: v18.0 or higher
- **npm**: v9.0 or higher

### 2. Installation
```bash
git clone https://github.com/your-repo/markopolo-frontend.git
cd markopolo-frontend
npm install
```

### 3. Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to view the application in development mode.

### 4. Production Build
```bash
npm run build
```
The build assets will be generated in the `dist/` directory, optimized for production deployment.
